# NCE Renewal Check: visual system

Current user contract, 4 October 2026. The opening questionnaire is removed. The check is a controls-only flow; Evidence and File guide are distinct information views. No explanatory text, subtitles, details disclosures or claim trails belong to the control page.

The initial screen has the established title, two file pickers, exact subscription ID, two compact optional selects and one primary action. Selecting a Pax8 file automatically starts bounded native discovery. Search and a native subscription selector appear when ready; no row is automatically selected. Choosing the empty option deselects and revokes the case. Inputs can be edited during discovery: canceled work is replaced by the latest fenced discovery. There is no Find or Change case button. Reset appears only after file selection. When confirmation or repair is needed, its workflow action replaces Check records.

Instrument Serif remains the 38px regular primary title font. Source Sans 3 remains the secondary font for labels, data and controls. Native select options use 19px system-ui, with full stops. The bright orange/yellow linked-square logo preserves the earlier silhouette. Fonts and images are local. Earlier radio-option, Add facts and inline inspection-disclosure layouts are superseded by the user's latest controls/information separation request.

Actions use intrinsic width, pill corners, centered 18px bold text, 12px by24px padding and a48px minimum height. Reference navigation uses links. File pickers share a row above720px; optional selects share a row above600px. These breakpoints follow usable control width, not the614px annotation. Labels and controls wrap without clipped text.

Evidence holds the canonical comparison explanations, source case, claim trail, source locators and original-file inspection. Workflow decision controls remain on the check page; they cannot act while hidden behind a reference view. Original-file navigation and saving are evidence utilities and grant no workflow authority. Reading finished evidence retains current custody and confirmation; entering it during pending processing cancels and revokes unfinished work. The information view and its opener have explicit ownership/readability checks. Merely hiding a reference view cannot authenticate a source or make a missing fact positive.

File guide is a separate minimal six-entry glossary with short definitions and example downloads. Terms and definitions share rows above600px and stack below. Full capability/resource policy owners stay in source; the old technical dump is removed from the UI. Exact glossary text/structure, file picker support and enforced read deadlines are checked. Opening the guide cancels processing and revokes current comparison authority while retaining native files and independent original-byte custody; returning requires a fresh check/confirmation.

Optional fields default to not-asked. Omitted opening facts enter the reusable model as unknown. The adapter says no answer was collected and labels supplied records as unauthenticated claims. CSVs cannot establish reseller responsibility. No positive eligibility or financial action is synthesized by the shorter UX. Operational progress/error feedback remains available for recovery. Development checks are distinct from full Principle3 qualification.
