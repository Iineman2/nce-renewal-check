# Contributing

Run `npm test` and `npm run check` with Node.js 24 or later. Serve `scope-fit/` over HTTP for browser checks; opening `index.html` through a file URL does not supply the required module Worker environment.

Keep behavior specifications, source, and meaningful regression coverage aligned. Treat supplied files as inert data. Preserve original bytes and provenance, exact case identity, current-selection permissions, bounded work, and cancellation semantics. New formats or remote processing require an explicit new handling and support contract.

Use synthetic data in commits and test artifacts. Do not commit customer records, credentials, local browser profiles, or generated traces. The main interface keeps controls distinct from the Evidence and File guide information views.

Historical QC packs are immutable evidence for their captured source. Changes require fresh receipts and a new proof owner; never change expected hashes, accepted counts, or audit dispositions solely to make an old gate pass. Report tested properties separately from untested scenarios and platform boundaries.
