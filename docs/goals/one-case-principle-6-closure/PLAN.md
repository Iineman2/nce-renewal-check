# Principle 6 audit closure

Goal: preserve evidence-bound one-case confirmation and reject invalid QC proof.
Approved input: user requested implementation and QC closure of the 420-condition audit.
Truth owners: private model receipt registry; app controls/File/date/policy and rendered evidence; QC proof content and independent review binding.
Cutover: confirmation commits only after post-owner coherence. Evidence freshness includes relevant ancestor identities and computed concealment checks. Earlier P6 proof is historical and preserved; new current proof belongs to output/one-case-principle-6-closure.
Displaced paths: unchecked post-owner mutation, ancestor/CSS hiding, signature-only images, ambiguous unit counters, approval of replacement evidence without fresh review.
Acceptance: all current unit/syntax/browser scripts, dedicated closure markers, strict content predicate tests, actual passing-baseline negative proof fixtures, independent POST/FINAL review and read-only sealed verification.
Kill criteria: stale confirmation/positive result, invalid content accepted, unbound review, missing proof or historical leaf drift blocks acceptance.
Forbidden: overwrite historical receipts, provider writes, financial authorization, deploy, commits, invented operator/provider acceptance.

Ordered board (main implements; independent agents review read-only):
1. UI coherence and visibility corrections, including clipping and readable material text.
2. Model lexical/ownership/maximal-resource regressions and UI successful-return faults.
3. Strict PNG/terminal-summary/review-digest predicates and negative fixture evidence.
4. Full current-source executions; POST review, negative runner, FINAL evidence review and seal.
5. Reconcile every audit row with exact evidence, representative guards or an explicit external/trusted-owner boundary. An unexecuted variant must not become an exact PASS by relabeling.

Support contract: decoded source text and exact selector bind model receipts. Explicit owner revocation remains required; a mismatched pure review is not destructive. Current File/control identity and local calendar/policy are app-owned. Concealment guard rejects hidden/inert/aria-hidden ancestors, display/visibility/zero opacity/content visibility/zero line height, clipping/masking and material text with zero area/font size. It conservatively rejects clipping/masking styles even when partial content could remain visible. It does not prove human readability for arbitrary CSS colors, overlays, extensions, full runtime compromise or actual assistive technology.
External acceptance: authentic native/provider revisions, human intent/comprehension, arbitrary browsers/devices and financial permission require external evidence. These are not fabricated passing test cases.
