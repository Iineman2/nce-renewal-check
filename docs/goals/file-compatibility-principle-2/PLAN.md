# Original File Evidence Fidelity Implementation Plan

**Intent:** Implement feature 1.3 principle 2 so an operator can recover the exact supplied file and trace every exposed CSV derivative to its source, without changing case or financial authority.
**Current Behavior:** Runtime returns only decoded text and loses BOM-sensitive byte identity; selected Pax8 evidence has record/raw-value locators but no cell/header byte locations; projected comparison rows lose private record association; failed/other-role files lack whole-original recovery.
**Expected Outcome:** One private byte-custody owner captures before transformation, hashes original bytes and supplies live role-bound handles, defensive recovery copies and bounded immutable projections. The sole CSV lexical owner preserves positional lexemes/ranges and compact skipped-record inventory; existing normalized-profile rejection and case rules remain.
**Target-Perspective Output:** The operator sees separate source disclosures for Pax8 and HaloPSA, can inspect positional/raw/normalized evidence, distinguish partial/rejected material, identify content independently of filenames, and save an exact inert original copy. A reviewer can independently compare downloaded bytes/digests/locators and the same-run proof pack.
**Truth Owner:** file-evidence.mjs for private bytes/live source references; runtime.mjs for acquisition/deadline/profile admission; csv-evidence.mjs as the sole scanner; preflight.mjs for row/claim/case/confirmation authority; app.mjs for guarded projection and existing lifecycle.
**Contract Boundary:** Current two normalized CSV profiles/three operations. Original capture establishes only fidelity. No additional reader, OCR, generic mapping, persistence/upload, source authentication, authority receipt or secure-memory-erasure claim.
**Cutover:** Redirect all three app reads through byte-owned acquisition; retain readLocalFile only as its text wrapper. Replace the embedded tokenizer with the shared lexical scanner. Carry private row locations through selectedRecord. Version changed reader/policy and selected-source evidence. Redirect current README/contract acceptance to the new owner.
**Displaced Path:** No second tokenizer/parser, byte reconstruction from text, metadata content key, competing current-case store, permissive evidence validator or copied prior approval.
**Value Density:** Exact original recovery, positional source fidelity and current operator inspection across both roles, plus bounded strict regression proof. Preserve established normalized/profile semantics rather than enabling future formats.
**Acceptance Evidence:** Independently authored byte/digest/location fixture oracles; meaningful model tests; real browser downloads and previews; all prior 357 model/45 browser semantic contracts plus new fixed tests; source/served binding, screenshots, 506 historical proof paths, 126 inherited proof predicates plus new fidelity negatives, actual independent reviews and sealed final verification.
**Evidence Lane:** Local synthetic native File and controlled byte/DOM/runtime/race failures. Exact new cases are distinct from inherited audit representative/external dispositions. No universal acceptance.
**Kill Criteria:** Original recovery differs; provenance points to another source/cell; ambiguous headers merge; stale/forged evidence survives; a failed/partial file becomes compatible; independent evidence is hidden; prior proofs change; source drifts after capture; required semantic gate disappears; important review finding remains.
**Architecture Slice:** Create scope-fit/{file-evidence.mjs,csv-evidence.mjs,file-evidence-view.mjs,file-evidence.test.mjs,ui-file-evidence.js,FILE_COMPATIBILITY_PRINCIPLE_2.md}; modify runtime/preflight/claims/app/index/file-support/current tests/README; create this goal package and output/file-compatibility-principle-2. Avoid all previous proof leaves/indices and original audit matrices. Pinned local accessibility checker remains unchanged.
**Plan Review Gate:** Requires actual independent PRE review before execution. Main implements sequentially. Read-only explorer/review/verifier slices may run independently.
